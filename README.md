# BMW Global Sales Analysis

## Project Overview

This project analyzes BMW global vehicle sales using Python. The analysis focuses on identifying sales trends, revenue distribution, customer preferences, and regional performance through data visualization.

---

## Objectives

- Clean and preprocess sales data
- Perform Exploratory Data Analysis (EDA)
- Identify sales trends
- Analyze revenue by country
- Study model performance
- Generate business insights

---

## Dataset

The dataset contains BMW global sales information including:

- Country
- Model
- Year
- Sales
- Revenue
- Fuel Type
- Transmission
- Customer Segment

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

---

## Project Workflow

1. Import Libraries
2. Load Dataset
3. Data Cleaning
4. Exploratory Data Analysis
5. Data Visualization
6. Business Insights

---

## Key Insights

- Highest selling BMW models identified.
- Revenue comparison across countries.
- Sales trend over years.
- Fuel type distribution.
- Customer segment analysis.
